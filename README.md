# Ink To Card 1.0.2

此版本发布时未保留独立 Git 提交，本快照的 src/ 和 web/ 运行源码从原始正式安装包完整还原。包内生成的共享脚本由 src/ 单一源码构建，不重复收录。版本元数据和重建脚本为归档时补建，原始开发测试与未打包文件不假设存在。

归档提交时间按原安装包的本地保存时间记录，不代表当时已有 Git 历史。原始安装包见 [v1.0.2 Release](https://github.com/642827083/Ink-To-Card/releases/tag/v1.0.2)。

## 本版功能

- 新增“无彩色书写”映射，确认已有可见手写但未检测到彩色时，可设置为指定卡色。默认不触发，支持单卡、自动跟随和批量处理。
- 保留已有七种笔色映射；少量彩色、未映射彩色、无手写或读取失败时，不会误用“无彩色书写”的卡色。
- 新增部分绘图的只读试验预览，便于与 MN 原图核对；尚未完整兼容的绘图仍不参与改色。
- 预览增加生成状态和读取、显示、超时失败提示；切换卡片后不显示旧预览。
