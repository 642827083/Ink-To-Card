# Ink To Card 1.0.3

此版本发布时未保留独立 Git 提交，本快照的 src/ 和 web/ 运行源码从原始正式安装包完整还原。包内生成的共享脚本由 src/ 单一源码构建，不重复收录。版本元数据和重建脚本为归档时补建，原始开发测试与未打包文件不假设存在。

归档提交时间按原安装包的本地保存时间记录，不代表当时已有 Git 历史。原始安装包见 [v1.0.3 Release](https://github.com/642827083/Ink-To-Card/releases/tag/v1.0.3)。

## 本版功能

- 新增双击插件图标开启／关闭自动跟随；单击仍用于打开或收起面板，双击不会先弹出面板。
- 自动跟随开启时插件图标保持高亮，收起面板后仍可确认开关状态。
- 精简面板，将当前卡片、跟随状态和识别结果集中到顶部，其他设置与排查工具按需展开。
- 预览支持展开、收起和点击图片放大；重开复用未变化的图片，笔迹变化后重新生成。
- 优化开关动画，保留现有开启颜色，并修复按钮、开关按压及处理中短暂变灰的问题。
- 扩展已核对手写绘图的兼容范围，部分此前只能预览的绘图可用于单卡、自动跟随和批量改色。
