# Ink To Card 1.0.1

此版本发布时未保留独立 Git 提交，本快照的 src/ 和 web/ 运行源码从原始正式安装包完整还原。包内生成的共享脚本由 src/ 单一源码构建，不重复收录。版本元数据和重建脚本为归档时补建，原始开发测试与未打包文件不假设存在。

归档提交时间按原安装包的本地保存时间记录，不代表当时已有 Git 历史。原始安装包见 [v1.0.1 Release](https://github.com/642827083/Ink-To-Card/releases/tag/v1.0.1)。

## 本版功能

- 记住已选定的卡片，取消选中或进入该卡编辑后仍继续跟踪笔色。
- 单选其他卡片时切换跟踪目标，面板显示当前跟踪的卡片。
- 自动检查间隔由约 1.2 秒缩短至约 0.3 秒，保留笔迹稳定等待。
- 切换卡片、离开学习集或进入后台时拦截旧识别结果，避免覆盖新的操作。

npm run check
