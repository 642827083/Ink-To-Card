# Ink To Card 1.0.0

此版本发布时未保留独立 Git 提交，本快照的 src/ 和 web/ 运行源码从原始正式安装包完整还原。包内生成的共享脚本由 src/ 单一源码构建，不重复收录。版本元数据和重建脚本为归档时补建，原始开发测试与未打包文件不假设存在。

归档提交时间按原安装包的本地保存时间记录，不代表当时已有 Git 历史。原始安装包见 [v1.0.0 Release](https://github.com/642827083/Ink-To-Card/releases/tag/v1.0.0)。

## 本版功能

## 首次正式版本

- 自动读取最后一条手写绘图，支持七种笔色映射。
- 提供主要颜色、颜色优先级及红色触发模式。
- 支持自动跟随、选中卡片批量处理和整个学习集批量处理。
- 提供绘图预览、来源检查和绘图样本导出。
- 修复页面持续显示“正在读取”的问题，并明确单卡识别需在脑图中选中卡片。
- 兼容已核对绘图样本中的手写直线。
- 更新为透明背景的灰色手写插件图标。
- 将下拉框、当前色号和改色提示统一显示为 1–16，与 MN 色板编号一致；原有映射和实际目标颜色保持不变。

npm run check
